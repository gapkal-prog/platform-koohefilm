# کوه فیلم — اکوسیستم کامل وردپرس برای سایت فیلم، سریال و انیمه

**طراح و توسعه‌دهنده:** ManaCore  ·  **قالب:** Koohe Film  ·  **نسخه:** ۱.۰.۰

مجموعه‌ای کامل و حرفه‌ای از یک قالب بلوکی (FSE) و سه افزونه، برای راه‌اندازی
سایت دانلود و تماشای فیلم، سریال و انیمه — با حالت تیره و روشن، ویرایش کامل
سراسری سایت، دریافت خودکار اطلاعات از منابع آزاد یا TMDB، و اشتراک ووکامرس.

```
koohe-film-1.0.0.zip               128K   (73 فایل)
koohe-film-complete.zip            324K   (بسته‌ی کامل)
```

</div>

اسکریپت پیش از بسته‌بندی، فایل‌های ترجمه را هم بازتولید می‌کند تا آرشیوها
همیشه `.pot` هم‌گام با کد داشته باشند.

### فایل‌های ترجمه

<div dir="ltr">

```bash
php wp/makepot.php      # یا: npm run wp:pot
```

</div>

| خروجی | دامنه‌ی متنی | تعداد رشته |
|---|---|---|
| `wp/plugins/manacore-core/languages/manacore.pot` | `manacore` | ۱٬۷۸۴ |
| `wp/themes/koohe-film/languages/koohe-film.pot` | `koohe-film` | ۲۴۴ |

هر سه افزونه یک دامنه‌ی متنی مشترک (`manacore`) دارند، پس هر سه در یک فایل
`manacore.pot` استخراج می‌شوند. استخراج‌کننده از توکنایزر خود PHP
(`token_get_all()`) استفاده می‌کند — بنابراین رشته‌های به‌هم‌چسبیده
(`'a' . 'b'`)، کوتیشن‌های escape‌شده و ۱۱ تابع i18n (شامل `_n`، `_x`، `_nx`)
را درست تشخیص می‌دهد و فراخوانی‌های متد (`->__()` / `::__()`) را رد می‌کند.
برای ترجمه، `.pot` را در Poedit باز کنید و به‌صورت
`manacore-fa_IR.po/.mo` در همان پوشه ذخیره کنید.

اسکریپت، نسخه را از هدر فایل اصلی می‌خواند و فایل‌های توسعه
(`.git`، `node_modules`، `*.map`، `tests` و …) را از آرشیو حذف می‌کند؛
ساختار پوشه‌ها استاندارد وردپرس است و مستقیماً قابل بارگذاری است.

## افزونه ManaCore Core

موتور اصلی سایت. ۳۵ کلاس + توابع کمکی در `includes/` (۳۷ فایل):

| کلاس | مسئولیت |
|---|---|
| `Post_Types` | ثبت ۶ نوع محتوا |
| `Taxonomies` | ثبت ۷ تاکسونومی |
| `Meta` | طرح ۴۹ فیلد متا + پاک‌سازی و اعتبارسنجی |
| `Metaboxes` | رابط کاربری متاباکس‌ها در ویرایشگر |
| `Links` | موتور لینک دانلود/پخش (کیفیت، فصل، قسمت) |
| `Query` | فیلترهای کوئری و منابع داده |
| `Ratings` | امتیاز، شمارش تماشا (رویداد واقعی پخش)، محاسبه‌ی «داغ» |
| `Watchlist` | فهرست تماشای کاربر |
| `Player` | پخش‌کننده‌ی درون‌سایتی + برگه‌ی پخش (Page Watch) |
| `Templates` | توابع رندر کارت، جدول مشخصات، لینک‌ها |
| `Blocks` | ثبت ۴۰ بلوک سمت سرور |
| `Block_Data` | داده‌ی ویرایشگر (پل به JS) |
| `Block_Query` | تبدیل ویژگی‌های بلوک به `WP_Query` |
| `Block_Visibility` | ارزیابی نمایش شرطی سمت سرور |
| `Block_Support` | ویژگی‌های ظاهری و قطعات مشترک رندر |
| `Settings` | پنل هفت‌تبی: عمومی، پخش و دانلود، درخواست‌ها، خرابی لینک‌ها، مگامنو، تحلیل و آمار، ابزارها |
| `Mega_Menu` | سرویس مشترک مگامنوی ژانرها (قالب + شورت‌کد + پنل مدیریت) |
| `Rest_Api` | ۸ نقطه‌ی پایانی REST |
| `Seo` | متا تگ‌ها، Open Graph، JSON-LD |
| `Assets` | بارگذاری CSS/JS |
| `Install` | نصب، جدول‌ها، نسخه‌بندی (پایگاه‌داده ۱٫۲٫۰) |
| `Reports` | گزارش خرابی لینک + صف رسیدگی مدیر |
| `Requests` | درخواست فیلم/سریال کاربران + رأی‌گیری، بازبینی و پنل «درخواست‌های من» |
| `Analytics` | داشبورد تحلیلی + ویجت پیشخوان (کش‌شده) |
| `Portability` | پشتیبان‌گیری/بازگردانی تنظیمات (JSON) از پنل و CLI |
| `Demo` | محتوای نمایشی یک‌کلیکی (قابل حذف اختصاصی) |
| `Downloads` | دانلود امضاشده (HMAC + انقضا + بررسی دسترسی)، پل دانلود و شمارش سرورسوی دانلود |
| `Links_Admin` | ستون وضعیت لینک، پالایه‌ی «دارای/بدون لینک» و پیوند سریع در فهرست پیشخوان |
| `Link_Tools` | ابزارهای گروهی لینک: جایگزینی پیشوند نشانی، کپی گروه لینک، بازرسی ساختاری |
| `Cli` | فرمان‌های `wp manacore status/export/import/demo/rebuild/cleanup/links-domain/links-copy/links-audit/links-check` |

### انواع محتوا

| اسلاگ | نام | توضیح |
|---|---|---|
| `movie` | فیلم | فیلم سینمایی |
| `series` | سریال | سریال تلویزیونی |
| `anime` | انیمه | انیمیشن ژاپنی |
| `episode` | قسمت | قسمت سریال/انیمه |
| `person` | عوامل | بازیگر، کارگردان، … |
| `collection` | مجموعه | مجموعه/فرنچایز |

### تاکسونومی‌ها

`genre` (ژانر) · `country` (کشور) · `release_year` (سال انتشار) ·
`network` (شبکه) · `studio` (استودیو) · `quality` (کیفیت) · `language` (زبان)

علاوه بر `category` و `post_tag` هسته‌ی وردپرس.

### لینک دانلود و پخش

- چند **کیفیت** برای هر اثر (۴۸۰p تا ۴K و BluRay/WEB-DL/…)
- ساختار **فصل → قسمت** برای سریال و انیمه
- افزودن/حذف/جابه‌جایی پویا در متاباکس، بدون بارگذاری صفحه
- تفکیک نوع لینک: دانلود مستقیم، پخش آنلاین، زیرنویس، تریلر
- برچسب زبان، حجم، کدک، دوبله/زیرنویس
- امکان علامت‌گذاری لینک به‌عنوان **ویژه‌ی مشترکین**
- **باکس سریالی داینامیک:** جدول فصل‌به‌فصل از دو منبع پر می‌شود —
  «بسته‌های کامل فصل» روی پست سریال و لینک هر قسمت روی پست همان قسمت
  (منبع با ویژگی «منبع ردیف‌ها» بلوک یا آرگومان `source` قابل تغییر است).
  هر ردیف، مالک خودش را می‌شناسد؛ یعنی امضای دانلود و شمارش روی همان
  قسمت انجام می‌شود و دکمه‌ی پخش به پخشِ همان قسمت می‌رود.
- **مدیریت از فهرست:** ستون «لینک‌ها» در فهرست فیلم/سریال/انیمه/قسمت
  (برای سریال، جمع لینک قسمت‌ها هم شمرده می‌شود)، پالایه‌ی
  «دارای لینک / بدون لینک» و پیوند سریع «لینک‌ها» روی هر ردیف.
- در نبود لینک، بازدیدکننده هیچ مارک‌آپی نمی‌بیند ولی مدیر راهنمای
  «افزودن لینک‌ها» را در همان جای باکس می‌بیند.

## ویرایشگر بلوک: تنظیمات کامل حلقه‌ها

هر یک از ۱۰ بلوک، در نوار کنار ویرایشگر تا **۹ پنل تنظیمات** دارد.
مجموع ویژگی‌های قابل تنظیم: **۶۲ ویژگی** برای «شبکه‌ی آثار» و
۵۲ برای «اسلایدر ویژه».

| پنل | تنظیمات |
|---|---|
| **محتوا و سرتیتر** | متن سرتیتر، سطح (H2–H6/div)، آیکن (۱۱ گزینه)، زیرعنوان، دکمه‌ی «بیشتر» با متن/آدرس/هدف |
| **منبع و کوئری** | ارث‌بری از کوئری صفحه، منبع (جدیدترین، منتخب، بالاترین امتیاز، پربازدید، داغ، تصادفی، مشابه، مجموعه)، نوع‌های محتوا، تعداد، پرش (offset)، حذف اثر جاری |
| **فیلتر تاکسونومی** | **قواعد چندگانه**: هر قاعده = تاکسونومی + ترم‌ها + عملگر (`IN` / `NOT IN` / `AND`)، با رابطه‌ی AND/OR بین قواعد |
| **فیلترهای پیشرفته** | جستجوی متنی، بازه‌ی سال، حداقل امتیاز، فیلتر پرمیوم، نوشته‌های چسبان، فقط دارای لینک، فقط دارای پوستر، نویسندگان، شناسه‌های شامل/مستثنی |
| **مرتب‌سازی** | ۱۵ گزینه (تاریخ، عنوان، امتیاز، بازدید، تصادفی، متای عددی/متنی، …) + کلید متا + جهت |
| **چیدمان** | نوع (شبکه، ریل افقی، فهرست، آجری، شاخص+فهرست) + ستون در دسکتاپ/تبلت/موبایل + فاصله |
| **نمایش کارت** | سبک کارت (پوستر/عریض/مینیمال/متنی)، نسبت تصویر، تگ عنوان، تعداد خط عنوان، **۱۲ کلید نمایش** (امتیاز، سال، نوع، کیفیت، ژانر، قسمت، بازدید، مدت، پرمیوم، فهرست تماشا، لایه‌ی رویی، چکیده)، تعداد کلمه‌ی چکیده، هدف لینک، کلاس دلخواه |
| **نمایش شرطی** | ← بخش بعدی |
| **پیشرفته** | کلاس افزوده، لنگر (anchor)، متن حالت خالی، پنهان‌سازی در صورت خالی بودن، مدت کش |

> (`Blocks::definitions()`) و همان تعریف با `window.manaCoreBlockRegistry`
> به JavaScript می‌رسد. بنابراین هیچ‌وقت دو فهرست ناهمگون از ویژگی‌ها
> وجود ندارد. پیش‌نمایش ویرایشگر با `ServerSideRender` انجام می‌شود، پس

## نمایش شرطی بلوک‌ها

پنل **«نمایش شرطی»** به مدیر اجازه می‌دهد مشخص کند هر حلقه یا بلوک
**کجا و برای چه کسی** دیده شود.

- **کلید فعال‌سازی** — تا خاموش است، هیچ محدودیتی اعمال نمی‌شود.
- **عمل** — «نمایش بده اگر» یا «پنهان کن اگر».
- **رابطه** — `AND` (همه‌ی قواعد) یا `OR` (حداقل یک قاعده).
- **قواعد چندگانه** — با دکمه‌ی «افزودن شرط»، بی‌نهایت قاعده.
- **عملگر هر قاعده** — «هست» یا «نیست» (`is` / `is_not`).
- **پنهان‌سازی بر اساس دستگاه** — موبایل، تبلت، دسکتاپ (با CSS، بدون JS).

### ۱۲ نوع قاعده

| نوع | ورودی | مثال کاربرد |
|---|---|---|
| `context` | زمینه‌ی صفحه (۱۰ گزینه) | فقط در صفحه‌ی اول |
| `post_type` | نوع محتوا | فقط در صفحه‌ی فیلم‌ها |
| `taxonomy` | تاکسونومی + ترم‌ها | فقط اگر اثر ژانر «اکشن» دارد |
| `archive_term` | تاکسونومی + ترم‌ها | فقط در آرشیو ژانر «کمدی» |
| `post_ids` | فهرست شناسه | فقط در چند برگه‌ی خاص |
| `login` | وارد شده / نشده | بخش عضویت فقط برای مهمان |
| `user_role` | نقش کاربری | ابزار مدیریتی فقط برای مدیر |
| `subscription` | سطح اشتراک | بخش ویژه‌ی مشترکین طلایی |
| `premium` | اثر پرمیوم است / نیست | نوار پرمیوم فقط روی محتوای آزاد |
| `has_links` | لینک دارد / ندارد | «به‌زودی» فقط بدون لینک |
| `date_range` | از تاریخ – تا تاریخ | کمپین نوروزی خودکار |
| `query_var` | نام و مقدار پارامتر | صفحه‌ی فرود کمپین با `?promo=summer` |

> **نکته:** در **ویرایشگر همیشه** بلوک نمایش داده می‌شود تا مدیر بتواند
> آن را ببیند و ویرایش کند؛ قواعد فقط در سایت اعمال می‌شوند.
> قاعده‌ی `query_var` هم متغیرهای ثبت‌شده‌ی وردپرس (پیوند یکتا و بازنویسی)
> و هم `$_GET` را پوشش می‌دهد.

## ریسپانسیو و دسترس‌پذیری

### نقاط شکست

هم‌مرز با هسته‌ی وردپرس تا رفتار قالب و هسته در مرزها یکی بماند:

| بازه | مرز | توضیح |
|------|-----|-------|
| موبایل | `max-width: 599px` | هسته ناوبری را در `min-width: 600px` افقی می‌کند |
| تبلت | `max-width: 781px` | |
| دسکتاپ | `min-width: 782px` | هسته ارتفاع نوار مدیریت را همین‌جا عوض می‌کند |

**نکته‌ی مهم:** مرزِ `max` و `min` هرگز نباید عدد یکسان داشته باشند؛ در
پهنای دقیقاً همان عدد، هر دو منطبق می‌شوند و قواعد موبایل و دسکتاپ با هم
اعمال می‌شوند. بخش ۱۲ آزمون این حالت را خودکار می‌گیرد.

### اندازه‌ی سیال

تیترها، شبکه‌ی پوستر و فاصله‌ها با `clamp()` نوشته شده‌اند، پس میان
۳۲۰px تا نمایشگرهای ۴K پیوسته تغییر می‌کنند و در نقطه‌ی شکست «پرش»
دیده نمی‌شود. روی نمایشگر ۱۶۰۰px و بالاتر، طول خط متن به `72ch` محدود
می‌شود تا خوانایی حفظ شود.

### هدف لمسی

روی نمایشگرهای لمسی (`@media (pointer: coarse)`) ناحیه‌ی کلیک هر عنصر
کوچک با یک شبه‌عنصر شفاف به **۴۴×۴۴ پیکسل** می‌رسد (توصیه‌ی WCAG 2.5.5)
**بدون آنکه ظاهر تغییر کند**. نقطه‌های اسلایدر هم در این حالت از هم
فاصله می‌گیرند تا نواحی لمسی روی هم نیفتند.

### دسترس‌پذیری

- حلقه‌ی تمرکز یکدست با `outline` (نه `box-shadow`) تا در حالت
  «کنتراست بالا»ی ویندوز هم باقی بماند؛ روی تصویر تیره سفید می‌شود.
- نتایج جستجوی زنده در ناحیه‌ی `role="status"` با `aria-live="polite"`
  و `aria-atomic` قرار دارند تا صفحه‌خوان آن‌ها را اعلام کند.
- `prefers-reduced-motion` همه‌ی جلوه‌ها را خاموش می‌کند.
- `prefers-contrast: more` مرزهای دیدنی اضافه می‌کند.
- پیوند «پرش به محتوا» در هر ۲۱ قالب هدف `#koohe-main` دارد.
- `overflow-wrap: anywhere` و `max-width: 100%` روی رسانه، جلوی
  سرریز افقی (رایج‌ترین ایراد موبایل) را می‌گیرد.
- `env(safe-area-inset-*)` برای گوشی‌های دارای بریدگی.

### نوار کنش پایین صفحه (موبایل)

گزینه‌ی سفارشی‌ساز `koohe_mobile_actionbar` (پیش‌فرض: روشن). در صفحه‌ی
اثر روی موبایل، دکمه‌های «دانلود و پخش» و «تریلر» را در دسترس شست نگه
می‌دارد. تنها زمانی چاپ می‌شود که:

1. صفحه‌ی یکی از انواع محتوای ManaCore باشد،
2. دست‌کم یک کنش واقعی (لینک دانلود یا تریلر) موجود باشد.

با فیلتر `koohe_actionbar_items` می‌توان کنش‌ها را تغییر داد:

<div dir="ltr">

```php
add_filter( 'koohe_actionbar_items', function ( $items, $post_id ) {
	$items['share'] = array(
		'type'  => 'link',
		'href'  => '#share',
		'label' => 'اشتراک‌گذاری',
		'class' => 'koohe-actionbar-btn',
	);
	return $items;
}, 10, 2 );
```

</div>

## راهنمای مدیر سایت

### افزودن یک فیلم

۱. **فیلم‌ها → افزودن فیلم**
۲. اگر افزونه‌ی منابع فعال است: در جعبه‌ی «دریافت اطلاعات» نام فیلم را
   جستجو کنید و **درج** را بزنید — عنوان، خلاصه، پوستر، ژانر، عوامل و
   امتیازها خودکار پر می‌شوند.
۳. در متاباکس **«لینک‌های دانلود»** با دکمه‌ی «افزودن کیفیت» ردیف بسازید:
   کیفیت، زبان، حجم و آدرس را وارد کنید. برای لینک ویژه‌ی مشترکین،
   کلید «ویژه‌ی اشتراک» را روشن کنید.
۴. انتشار.

### افزودن سریال با فصل و قسمت

۱. ابتدا خود **سریال** را بسازید.
۲. در متاباکس لینک‌ها، «افزودن فصل» و سپس «افزودن قسمت» را بزنید؛
   برای هر قسمت می‌توانید چند کیفیت تعریف کنید.
۳. یا برای هر قسمت یک نوشته از نوع **قسمت** بسازید و سریال والد را
   انتخاب کنید (مناسب سایت‌های پرمحتوا و بهتر برای سئو).

### ساخت صفحه‌ی اول دلخواه

۱. **نمایش → ویرایشگر → قالب‌ها → Front Page**
۲. بلوک **«اسلایدر ویژه»** را بالای صفحه بگذارید و در پنل «منبع و کوئری»
   منبع را «منتخب سردبیر» بگذارید.
۳. چند بلوک **«شبکه‌ی آثار»** اضافه کنید و هر یک را تنظیم کنید —
   مثلاً یکی «جدیدترین فیلم‌ها»، یکی «داغ هفته»، یکی «انیمه‌های برتر».
۴. برای هر بخش، در پنل **«فیلتر تاکسونومی»** ژانر یا کشور دلخواه را
   انتخاب کنید.

### نمونه‌های نمایش شرطی

| هدف | تنظیم |
|---|---|
| بخش «عضو شو» فقط برای مهمان | قاعده `login` = وارد نشده |
| بخش ویژه فقط برای مشترک طلایی | قاعده `subscription` = طلایی |
| حلقه‌ی «انیمه‌های مشابه» فقط در صفحه‌ی انیمه | قاعده `post_type` = انیمه |
| بخش ویژه فقط در آرشیو ژانر اکشن | قاعده `archive_term` = ژانر/اکشن |
| کمپین نوروزی خودکار | قاعده `date_range` = ۱ تا ۱۳ فروردین |
| نوار جستجو پنهان در موبایل | پنهان‌سازی دستگاه = موبایل |

### ثبت کلید TMDB

**ManaCore → منابع داده** → کلید را در فیلد «TMDB API Key» بگذارید و

**اصل حاکم بر این آزمون‌ها:** هر آزمون باید «غیرتهی» باشد؛ یعنی با
بازگرداندن باگ اصلی، دقیقاً همان گزاره‌ها شکست بخورند. سه دسته اشکالِ
بی‌صدا که مرتب تکرار می‌شدند و اکنون خودکار گرفته می‌شوند:

- **گزینه‌ی بی‌اثر** — گزینه‌ای که در ویرایشگر دیده می‌شود ولی در خروجی
  کاری نمی‌کند (فهرست موازی در JS، یا نبودِ CSS متناظر).
- **گزینشگر یتیم** — قاعده‌ای که کلاسی را هدف می‌گیرد که هیچ‌جای
  PHP/JS/HTML تولید نمی‌شود، پس هرگز منطبق نمی‌شود.
- **متغیر مرده** — `var(--x)` خوانده شود ولی `--x` هیچ‌جا تعیین نشود.

### بررسی نحوی

<div dir="ltr">

```bash
# PHP
find wp/plugins wp/themes -name "*.php" -print0 | xargs -0 -n1 php -l

# JavaScript
for f in $(find wp/plugins wp/themes -name "*.js"); do node --check "$f"; done
```

</div>

نتیجه‌ی فعلی: **همه‌ی ۱۱۲ فایل PHP و ۱۰ فایل JS بدون خطا.**

رابطه‌ی AND/OR، عمل نمایش/پنهان، عملگر «نیست»، کلاس‌های دستگاه و

### استانداردها

- استاندارد کدنویسی وردپرس (نام‌گذاری، فاصله‌گذاری، تورفتگی با tab)
- همه‌ی خروجی‌ها با `esc_html`، `esc_attr`، `esc_url`، `wp_kses_post`
- همه‌ی ورودی‌ها با `sanitize_*` پاک‌سازی می‌شوند
- بررسی `nonce` و `current_user_can` در همه‌ی عملیات نوشتن
- کوئری‌ها با `WP_Query` و `$wpdb->prepare`
- آماده‌ی ترجمه — ۲٬۰۲۸ رشته در `__()` با دامنه‌ی متنی درست و
  فایل‌های `.pot` تولیدشده (بازتولید با `php wp/makepot.php`)
- بدون مرحله‌ی build — JS بدون JSX و بدون وابستگی npm
