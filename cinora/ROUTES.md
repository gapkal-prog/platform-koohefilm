# Cinora static route map

The static conversion uses these paths in links and JavaScript:

| Next-style route | Static route |
|---|---|
| `/` | `index.html` |
| `/movies` | `browse.html?type=movie` |
| `/series` | `browse.html?type=series` |
| `/browse`, `/categories` | `browse.html` (preserving query parameters such as `?type=movie`, `?type=series`, `?genre=`, `?sort=`, `?country=`, and `?q=`) |
| `/movie/:slug`, `/movies/:slug`, `/series/:slug` | `detail.html?id=:slug` |
| `/watch/:slug` | `player.html?id=:slug` |
| `/account` | `account.html` (preserving `?tab=`) |
| `/subscription` | `subscription.html` |
| `/magazine` | `magazine.html` |
| `/magazine/:article` | `article.html?id=:article` |
| `/schedule` | `schedule.html` |
| `/live` | `live.html` |
| `/cast` | `cast.html` |
| `/cast/:person` | `cast.html?id=:person` |
| `/help` | `help.html` |
| `/about` | `about.html` |
| `/terms` | `privacy.html` |

All catalog and editorial image paths remain the source values from `catalog.ts` (the repository's `/images/...` paths). Query parameters are URL encoded when generated by JavaScript.
